# Pre-release security audit (MVP) — 2026-11-22

Scope: the whole app (NestJS GraphQL API, Postgres with forced RLS, React web, nginx), including the
newest features: AI summaries (E5) and the md2slides integration. Method: the repo's
`saas-security-audit` checklist (19 checks) plus the OWASP Web, API and LLM Top 10. Checked
statically in code and against the migrated test database; behaviour is covered by the test suites.
Production infrastructure (TLS, buckets, DNS) was not reachable and is listed under "Not verified".

## SaaS security audit — 19/19 PASS or FIXED

| # | Check | Status | Where | What changed / what's needed |
|---|-------|--------|-------|------------------------------|
| 1 | Row level security | FIXED | `migrations/1730170000000-revoke-runtime-migrations-table.ts` | All 66 app tables have **forced** RLS, none with `USING (true)` (queried `pg_class` / `pg_policies`). The runtime role had read/write on TypeORM's `migrations` table through default privileges; revoked (only the migration owner needs it). ## Needs your action
- **Rotate the Gemini and Cloudflare keys** (they were shared in a chat) and set them only in the server environment.
- **TLS**: terminate HTTPS in front of the web container and redirect HTTP→HTTPS there; set `BETTER_AUTH_URL` and `CORS_ORIGINS` to the https origin.
- **Production env**: `REDIS_URL` (now also used for rate limits), S3, SMTP, `TURNSTILE_SECRET_KEY`, ClamAV. Super admins need two-step sign-in before opening the admin console (or set `PLATFORM_ADMIN_REQUIRE_TWO_STEP=false` knowingly).
- Optional hardening: give Better Auth its own database role so the app role can't read `session` / `account` at all.

## Not verified
- Production TLS, headers as served by the real load balancer, and live bucket privacy.
- Rate limits against a real Redis cluster (covered by unit tests with a Redis stand-in).
- AI calls hold the request's database transaction open while the model answers (up to `AI_TIMEOUT_SECONDS`); fine at MVP scale, worth moving outside the transaction if AI use grows.
